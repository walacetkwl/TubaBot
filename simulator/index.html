TubaBot v2 · Simulador

Executa o mesmo núcleo C++ do firmware (WebAssembly): tela redonda 466×466, toque, sensores e som. Não é emulação elétrica do ESP32-S3.

Alto-falanteMotor (opcional)

Como usar

Clique e arraste na tela como num celular. Toque no rosto = "boop"; dois toques = troca expressão; acariciar (arrastar devagar) = carinho; segurar parado 2 s = amor. Deslize para cima = apps, para baixo = ajustes rápidos, para os lados = relógio e "Hoje". Nos apps, deslize para a direita para voltar. Segurar 8 s em qualquer lugar = configuração.
